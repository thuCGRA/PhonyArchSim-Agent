# MRR 权重组分组评估

`arch.topology.weight_bank_groups` 在 SimPhony `real` 模式下为 MRR 权重组提供一组或两组。两组要求总波长数为偶数。两组各使用一半波长并各配一套激光源、微梳和读出链。两组共用相同的变体规格。总权重单元数、输入驱动器数、矩阵分块和目标 MAC 数保持相同。对称分组平分每核的光功率分配因子，在等插损时保持所需总光功率一致。光路插损按两条路径中的最大值计算。

两种 MRR 方案按每核一个空间输出建模。波长并行度只用于 GEMM 归约维度 `D`，不会再次计入空间输出维度 `M`。采用旧映射规则得到的 MRR 结果需要重新评估后才能与本实验比较。

每组对不相交的权重下标求部分和。理想实数模型中，两组部分和之和等于原点积。对已量化的两个有符号部分和，`b_out + 1` 位的加法器可以精确表示它们的和。读出后再归约改变了量化位置，数值一致性仍取决于量化步长、满量程和输出截断。成本报告不估算任务精度、串扰或模拟误差。

数字归约成本计入总能耗、面积和时延。当前估计使用每核一个加法器，假定每比特每次加法消耗 0.003125 pJ、占用 4 µm²，每批增加一个不重叠的时钟周期。报告保留逐层的加法次数和时延。系数是评估假设，未经过综合或测量。

## 同配置对照

`vit_tiny`，16 个波长，4 个 Tile、每 Tile 2 个核心，4 bit ADC 输出。在 21 个被评估层上，单组和双组的矩阵分块及迭代数完全相同。

| 指标 | 单组（16） | 双组（8 + 8） |
|---|---:|---:|
| 总能耗（mJ） | 3.895 | 3.987 |
| 总面积（mm²） | 8.843 | 16.162 |
| 总时延（ms） | 66.967 | 71.392 |
| 核心最大插损（dB） | 2.3 | 2.3 |

第二套激光源与微梳增加了 7.296 mm²，占此次额外面积的大部分。双组采用 5 bit 加法器，模型计入 4.424 ms 的额外归约时延。结果仅适用于独立光源与微梳的双组实现，以及此处采用的读出和归约时序假设。

用下列参数运行 `scripts/experiments/verify_search_space.py`，并把 `--output-dir` 和 `--db` 指向绝对路径，可复现该对照。

```text
--workloads vit_tiny --core-kind mrr_weight_bank --params weight_bank_groups --only weight_bank_groups
```
