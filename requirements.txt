# photonic-tuner — native LangChain + LangGraph runtime dependencies.

# Install into a Python >=3.11 venv, e.g.:
#
#     .tools/uv venv .venv-agent --python 3.14
#     .tools/uv pip install --python .venv-agent/bin/python -r requirements.txt
#
# The real SimPhony stack pins torch 1.12.1 / Python 3.10, so it cannot share
# this interpreter.  It lives in a separate venv (`.venv-simulator`, see
# scripts/env/requirements-real.txt) and is reached over an MCP stdio bridge
# (photon_tuner/bridge/mcp/simphony_server.py), not imported in-process.
